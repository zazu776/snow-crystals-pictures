# 雪の結晶図鑑 / Snow Crystal Atlas

Three.jsで動く、6種類の雪の結晶を観察する3D図鑑です。

## 起動

`index.html` をダウンロードしてダブルクリックしてください。Three.js・OrbitControls・CSS・アプリ本体をHTMLに同梱しているため、ネット接続やローカルサーバーは不要です。WebGL 2対応のブラウザで開いてください。

## 収録している結晶

- 六角板
- 星状六花
- 樹枝状六花
- 角柱
- 針状
- 鼓型

## 操作

- カードをクリックして結晶を選択
- ドラッグで回転
- ホイールまたはピンチでズーム
- 自動回転の切り替え、正面表示、視点リセット

形の特徴を表現した模式モデルです。厚み・大きさは比較用に調整しています。

## ファイル

- `index.html`: 単独で開ける配布版
- `main.js`: 編集用JavaScriptソース
- `style.css`: 編集用スタイル

配布版はソースとThree.js 0.180.0を同梱しています。ソースを変更した場合は配布版の再生成が必要です。

分類参考: [Ken Libbrecht — A Guide to Snowflakes](https://www.snowcrystals.com/guide/guide.html)

検証: Chromiumでネット接続を切ったローカルファイルからの起動、6種類の選択、自動回転切り替え、正面表示、視点リセット、スマートフォン幅のレイアウトを確認済み。
